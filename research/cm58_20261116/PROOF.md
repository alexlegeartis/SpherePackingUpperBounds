# One certified coset, three classes by complex multiplication

The construction is an explicit rank-58 lattice of minimum **exactly 10**.
Its new ingredient here is a certified half-coset and its compatible
order-three orbit, rather than three independent coset searches.

## Published parent and exact Gram binding

At p=29, Schütt–Shioda's *Mordell-Weil Lattices*, Theorem 13.35,
p.357 (2017 author draft), gives the lattice of

```
y² = x³ + 1 + t^30 over F_(29²)(t),
rank 56, minimum 10, Gram determinant 29^8.
```

The parent construction and its minimum are inherited published inputs.
The polynomial sections on p.359 make the input explicit. Work over
F_(29²)=F_29[i], i²=2, with a+29b encoding a+bi. Each saved unitary matrix
U=[[a,b],[c,d]] gives

```
x_U(t)=-(at+b)^10, y_U(t)=(ct+d)^15.
```

The verifier checks all 120 unitary identities and curve equations.
All these sections are disjoint from the zero section. Finite singular
fibres have type II; a unitary section cannot pass through their cusp,
since at+b and ct+d cannot both vanish. The chart at infinity is smooth,
with x'=s^10 x, y'=s^15 y. Hence Theorem 6.23, Eq.(6.15), p.123 gives

```
<P,Q> = 5 - (P.Q),  <P,P>=10.
```

For distinct non-opposite sections the finite intersection number is the
degree of gcd(x_P-x_Q,y_P-y_Q). The infinity contribution is the minimum
of 10-deg(x_P-x_Q) and 15-deg(y_P-y_Q), omitting identically zero
differences. This computes all **7,140 pairwise heights** directly.

The integral point-coordinate matrix Y and Gram G satisfy

```
Y G Y^T = the computed height Gram,
HNF(Y)=[I_56;0], det(G)=29^8.
```

Thus G is the lattice generated by actual polynomial points, and its
index in the published parent is one. An exact unimodular T gives the
reduced Gram Q=T G T^T used for the enumeration.

## The complete coset certificate

The nonzero binary row c has c Q c^T=2 modulo 4. For every integer z=c
modulo 2, z Q z^T=2 modulo 4. The full enumeration excludes every such z
with norm at most22. The next permitted norm is26, so

```
min ||c/2 + L||² >=26/4=13/2.
```

Two complete runs of the same audited enumerator each visited
**2,904,500,151 nodes**, with no leaf below the cutoff. Both reports are
retained. An exact norm-22 witness in a different class supplies the
negative control. This is a fresh replay of the same implementation,
not an independent enumeration algorithm.

Every LDL identity and dyadic enclosure is regenerated exactly by the
Python auditor. The C++ enumeration uses outward-rounded IEEE-754
binary64 bounds, exact integer accumulation of dyadic centres and exact
integer leaf norms, under the stated compiler flags. Unsafe coordinate
ranges abort. As with the earlier P48 certificates, these arithmetic and
compiler assumptions are explicit proof dependencies.

## Complex multiplication transports the certificate

The integral matrix C satisfies

```
C Q C^T=Q, C²+C+I=0, det(C)=1.
```

It was obtained from complex multiplication by a cube root of unity on
the j=0 parent curve; the identities above suffice for the packing proof.
The three binary classes c, cC and cC² are distinct and nonzero, and
c+cC=cC² modulo 2. Indeed a fixed nonzero binary class would contradict
C²+C+I=0. All three classes have the certified depth 13/2, because C is
an exact lattice isometry. A single complete exclusion therefore proves
all three inequalities.

## The full 58D lattice

Let B have rows c and cC modulo 2, and put

```
M=(7/4) Gram(A2)=[[7/2,-7/4],[-7/4,7/2]].
G58=[[Q, Q B^T/2],
     [B Q/2, B Q B^T/4+M]].
```

Every nonzero binary vertical parity has horizontal squared norm at
least13/2 and vertical squared norm at least7/2. For nonzero integer
(a,b), a²-ab+b² is a positive integer, proving the latter vertical
minimum. All-even nonzero vertical coefficients have norm at least14.
A zero vertical vector inherits the parent minimum 10. Therefore the
full minimum is at least10. A parent basis vector of norm 10 remains in
