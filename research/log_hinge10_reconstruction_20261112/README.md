# 10D reconstruction discovery and exact export

This reconstructs a fresh certificate after the earlier unpublished package
was unavailable. It is not byte-identical recovery of the previous result.
Final exact result: density < 0.143330282. The proof package remains the
acceptance authority; sampled feasibility and LP statuses are not proofs.

## Deterministic export

Install python-flint 0.9.0 and run `python export_exact.py --output exported`.
The frozen inputs are the angular optimizer output, final log-hinge fit and
root-cut-refitted radial output. The exporter interprets floating source
coefficients as exact binary64 rationals, applies the documented repairs,
and regenerates every angular and radial coefficient. The fit's decimal
parameters are frozen as printed rationals in the proof.

The exported `angular.json`, `fit.json` and all mathematical fields of
`certificate.json` reproduce the proof inputs exactly. Diagnostic metadata
in the proof certificate is not generated by this minimal exporter.

## Fresh numerical search

The scripts under `search` are the actual discovery programs. They derive
from the published 16D log-hinge and 11D curved-profile tools at commit
043b11949c629d2fe977db14f29ce174653c4068. In a fresh copy of `search`, create
`inputs` and copy `inputs/scaling_reference15.json` there. Despite its
historical filename, this scaling vector was taken from the published 11D
angular certificate and only preconditions the numerical linear program.
Then run, in order:

    python screen.py --dimension 10 --a 8 --b 16 --rounds 4
    python rebuild.py 10
    python refine_profile.py 10
    python refit_radial.py 10
    python exact_radial.py 10

Keep OPENBLAS_NUM_THREADS=1. The scripts also set it internally. Fresh
optimization may produce different floating coefficients. The first
log-hinge fit had a positive cyclic violation near 3.9e-6 and was rejected.
The dense margin-refined fit passed numerical separation with margin about
9.7e-6. The first radial mesh had Fourier violations; two root-cut rounds
removed them. Final exact repair and proof replay, not this mesh check,
establish the bound. Logs preserve those rejected intermediate stages.

The chosen final proof parameters are a fixed exact angular polynomial,
14 nonnegative log-hinge coefficients, radial degree 63, squared separation
5/4, degree-one repair epsilon=1/1000000, and C enlargement 1000001/1000000.
The proof uses no external neighbor-count input.
