# Search provenance only

These files are not proof inputs. The full-geometry search contains numerical candidates in other dimensions and shell widths that have not been certified. Only the two 22D candidates identified in the package README are proved here.

The completed 22D density activation used the stronger auxiliary constants, but its multipliers were effectively zero and its numerical density was about 0.00387352264, worse than the pinned comparison 0.0037259419689206. It was not promoted as a density certificate. The activation source is retained for provenance, not as a standalone executable task; its original exact Schur seed and broader search environment are outside this portable proof package. No activation candidate is a proof input.

Searches require NumPy and SciPy, and the density activation additionally requires CVXPY and Clarabel. None is required for the exact proof replays.
