# Density extensions, normal sections, and finite antipodes

**Checkpoint: no new sphere-packing density record was obtained.** This directory contains searches near the new 36D lattice, exact rejection witnesses for saved torsion shifts, reproducible P48n vector pools, reference-section witnesses, and finite dual-cluster searches. Numerical discovery outputs are explicitly distinguished from exact statements.

All densities below are **center densities**: a lattice of minimum squared norm \(\mu\) and Gram determinant \(d\) has \(\delta=(\mu/4)^{n/2}/\sqrt d\). Multiply by the unit-ball volume to obtain ordinary packing density.

## 36D to 37D

For an extension generated by \((L_{36},0)\) and \((s,h)\), retaining minimum 8, the new center density is \(\sqrt2\,\delta_{36}/h\). Beating the 37D reference therefore requires

\[
h^2<\frac{17592186044416}{10090298369529}=1.74347530669\ldots,
\qquad d(s,L_{36})^2>6.25652469331\ldots.
\]

If \(2s\in L_{36}\), the vector \((0,2h)\) forces \(h^2\ge2\), so the density is at most \(\delta_{36}<4\sqrt2\). More generally, any packing consisting of two copies of this fixed section per purely vertical period \(H\) has \(H^2\ge8\), giving the same upper bound on its center density. This is a restriction on the specified stacking construction, not an obstruction to general 37D packings.

The CVP/SVP searches use floating enumeration, so the high-score candidates are not certified holes or packings. No covering-radius upper bound is claimed. The joint 37D numerical candidate reaches only 83.18% of the reference density.

## P48n normal sections and antipodes

`p48n_glue_pool.py` reconstructs **300,457 distinct antipodal norm-6 rays**, checking integer lattice membership and every norm exactly. `extend_normal_pool.py` adds pair differences, producing **600,454 rays** with norm counts 300,457 / 149,997 / 120,000 / 30,000 at squared norms 6 / 8 / 10 / 12. These are finite pools, not complete shells.

The pool generator uses the saved E8 gluing data in the sibling `KissingNumbers` checkout, commit `6ec8b9e6d1007a3dbe59fab68e96de51aad35524`. Its purpose here is to recover ambient lattice vectors; kissing-number bounds are not used as density bounds.

Rank-9/rank-10 normal exchange searches completed 129 trials with the norm-6 pool and 39 more with the mixed-norm pool, each with up to 100 exchange steps. The final trial in each time-budgeted run was partial: at least 16,600 and at most 16,800 exchange steps were performed, and the exact final step counters were not logged. The best primitive determinants remained **21870 and 54675**, reproducing the 39D and 38D references. `verify_normal_witnesses.py` independently checks the saved normal Gram matrices, ambient determinant 1, saturation indices 1, and density formulas. Minimum 6 of P48n is inherited from the published mother lattice, not re-enumerated in dimension 48.

For a primitive rank-\(k\) normal sublattice \(K\) of P48n and a finite subset \(S\subset K^*\) of diameter squared \(\beta<6\), the antipode density in dimension \(48-k\) is

\[
\delta=\frac{|S|}{\sqrt{\det K}}\left(\frac{6-\beta}{4}\right)^{(48-k)/2}.
\]

`antipode_general.py` searches the normal subspace and the finite cluster together, with the known 43D six-point cluster as a control. `antipode_one_row.py` evaluates every distinct one-row Gram pattern from the specified finite pool around the selected 43D seed. Their result summaries record exact candidate counts and scope. The short-dual enumeration is capped at 128 rays and the cluster discovery is greedy, up to 18 points; these searches are not exhaustive over all clusters. Any proposed improvement must pass exact Gram, primitive saturation, dual membership, diameter, and rational density-ratio checks before a candidate file is written.

| Completed antipode search | Configurations evaluated | Outcome |
|---|---:|---|

| Joint normal/cluster walk, dimensions 38–39 | 9,687, including 2 controls | References reproduced; no improvement |

The one-row screen finished in 21.6 seconds. Across the five omitted rows it encountered 2,604 / 2,698 / 2,651 / 2,632 / 2,449 distinct patterns before removing Gram duplicates between groups. Its finite normal-row coverage is complete for this one seed and pool; it does not exhaust other embeddings, all P48n vectors, or all dual clusters. All three summaries contain empty `new_verified_candidates` lists.

## Reproduction

Run from the repository root with Python, NumPy, SciPy, SymPy, `fpylll`, and `cysignals` available. These runs used one BLAS thread per process and CPUs 4–5. Time-budgeted search counts can vary with machine speed.

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
R=research/density_breakthroughs_20261113/gluing
python "$R/verify_extension_thresholds.py"
python "$R/verify_normal_witnesses.py"
python "$R/prepare_contacts36.py"
python "$R/search_torsion.py" --denominator 3 --seed 1313 --seconds 300
python "$R/search_torsion.py" --denominator 5 --seed 1315 --seconds 300
python "$R/voronoi_walk.py" --seed 17 --seconds 360 --batch 50
python "$R/metric40_screen.py" --contacts-only
python "$R/section_metric_screen.py" --dimension 39
python "$R/section_metric_screen.py" --dimension 40
python "$R/p48n_glue_pool.py"
python "$R/extend_normal_pool.py"
python "$R/p48n_normals.py" --seconds 500 --pool P48n_extended_normal_pool.npz --tag extended
python "$R/antipode_general.py" --seconds 480 --ranks 5,6,7 --tag antipode_41_43
python "$R/antipode_general.py" --seconds 480 --ranks 9,10 --seed 391038 --tag antipode_38_39
python "$R/antipode_one_row.py" --seed-limit 1
```

The antipode scripts expect the pinned external sphere-packing checkout at `../seed_deformations/external_sphere_packing` relative to this directory. `joint37.py` additionally uses the contact enumeration in `../contact_walk/contacts_reduced.txt`. Rebuildable pools and contact arrays are excluded from git by the local ignore manifest; compact exact normal witnesses, rejection witnesses, summaries, and generator code are retained.
