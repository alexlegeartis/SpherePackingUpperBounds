## Comparison scope and sources

The comparison columns reproduce the **lattice** section of a user-supplied snapshot of [Henry Cohn’s sphere-packing table](https://cohn.mit.edu/sphere-packing/), received on 2026-11-16. The snapshot contains no extraction date; this is not a claim that the live page was fetched or is unchanged. For rows drawn from the snapshot, every new upper is smaller than the corresponding upper there. The 38D comparison is separately identified below. For dimensions 14–22 and 25–36, its listed previous upper bounds are attributed to [Nina Zubrilina, *Improved lattice-packing bounds in small dimensions*](https://arxiv.org/abs/2610.35830).

For 23D, 37D and 45D–48D, the prior uppers are Alex Kravatskiy’s unrestricted-packing bounds, which also apply to lattices; the new certificates improve them only for lattices. These live Cohn rows were checked on 2026-11-16 and matched the snapshot. Each package links its corresponding unrestricted predecessor. [Earlier unrestricted proof](verifications/dim37/refinement_profile20261114/README.md). The snapshot gives more digits than the outward claims in the original source certificates. The JSON retains both the snapshot comparison upper and the original certificate-claim upper. Original comparison certificates are preserved from the [pinned upstream repository](https://github.com/AstroNinja389/lattice-packing-bound/tree/340a0e93bb95942c2b1b80092be43149504970eb/certificates). The 14D, 15D and 18D prior certificates are exactly replayed because those arithmetic proofs require them; later global-coupling results have no prior-density assumption.

Known lattice lower values are the displayed values in the same snapshot, not the generally larger nonlattice entries in its unrestricted table. They are rounded/truncated comparisons, not exact decimal identities or independently exhaustive current-record claims. In 36D the snapshot already cites this repository’s lattice construction. Gap decrease is `(U−U′)/(U−L)` using these displayed values; upper decrease is `(U−U′)/U`. These are comparison statistics, not new theorems.

This establishes improvements over the supplied snapshot and the named source benchmarks, not optimality or an exhaustive worldwide-priority guarantee. The snapshot credits this repository’s general-packing upper bounds in 23D and 37D–48D. The new 23D, 37D and 45D–48D lattice-specific improvements are included above; the unrestricted results remain in the separate unrestricted table rather than being duplicated here.

## Method and reproducibility

The 14D, 15D, 16D and 18D certificates combine Zubrilina’s modulo-two class framework with arithmetic near-frame constraints, exact torsion exclusions, and exhaustive first-n profile dual bounds. The determinant step overlaps [Géraud-Stewart and Naccache, Appendix D, Lemma 32](https://eprint.iacr.asia/2026/2826.pdf); it is attributed and not claimed as new.

The 17D, 19D–22D and 25D–37D and 45D–48D certificates use global short-class angular coupling, continuous Gegenbauer polynomial inequalities, and exact projective multiplicity bounds. They have no arithmetic trace-gap or prior-density assumption. Proof documents explain the continuous geometry and source-count normalization. Every published result has a complete executable exact proof.

The 23D certificate instead uses conditioned nested Gram-moment class profiles, with exact rank inequalities for every long-prefix cutoff and every short-bin branch. It has no pair-sum angular cuts or prior-density premise. Its default full verifier uses SymPy, optionally accelerated by public python-flint.

Run the separate lattice suite without changing the historical unrestricted suite:

```sh
python verifications/lattice/replay.py
# Or one dimension:
python verifications/lattice/replay.py --dimension 36
```

Python 3.10+ is required; the earlier dimensions use SymPy. The default20D–22D and25D–36D verifiers, except the stronger32D and35D refinements, use only the standard library, with exact compactified-half-line Bernstein sign proofs. The stronger32D and35D refinements and the37D and45D–48D defaults use SymPy and exact rational Bernstein tail signs;45D–48D use Fourier Bernstein subdivision with optional public python-flint, or exact SymPy root counts without it. The other SymPy-based defaults use Fourier root counts. Separate optional SymPy verifiers are included. Public `python-flint` is an optional speed improvement, not a private dependency.

Large JSON inputs use deterministic gzip. The replay checks stored and decompressed SHA256 hashes, materializes a temporary copy, and runs the complete proof there. Audited certificate bytes are preserved. Do not use `python -O`. Hosted Actions have not been enabled or dispatched.
