# Dimension-16 comparison sources

The pinned published general packing-density comparator is 0.02492121,
Table 1, dimension 16, of arXiv:2512.04829v2 (8 December 2025):
https://arxiv.org/html/2512.04829v2
The HTML renders the final column value with internal digit spacing as
`0.0249 2121`. The table was retrieved again on 11 November 2026.
The older Cohn-de Laat-Salmon column in that table is 0.02499441.

The achieved Barnes-Wall lower density is exactly

    L = pi^8 / 645120 = (pi^8 / 8!) * (1/16).

Here 1/16 is the center density of BW16, whose minimum squared norm is 4
and Gram determinant is 256. Sources:

- https://www.math.rwth-aachen.de/~Gabriele.Nebe/LATTICES/BW16.html
- https://www.math.rwth-aachen.de/~Gabriele.Nebe/LATTICES/density.html
- https://numberdb.org/T148 (explicit exact center-density and ordinary-density formulas)
- https://cohn.mit.edu/sphere-packing/ (indexed table; index freshness about four months)

These are comparisons to an explicit published upper value and an achieved
lower construction. No claim that a new candidate is valid follows from
this file, and a literature check cannot prove exhaustive record status.
The widened spherical-code count candidate in this folder is not a packing
density by itself.
